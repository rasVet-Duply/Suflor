# Чек-лист проверки (на тестовом ПК)

Отметьте результат для каждого пункта. Перед тестами: `Install.ps1`, вход под учеником.

1. [ ] Включение компьютера → вход под учеником → открылся SchoolDesk, а не рабочий стол.
2. [ ] Автозапуск после входа; нет панели задач/рабочего стола.
3. [ ] Перезагрузка → снова SchoolDesk.
4. [ ] Полное выключение и включение → снова SchoolDesk.
5. [ ] Chrome запускается из плитки.
6. [ ] Word и Excel запускаются (проверьте и PowerPoint).
7. [ ] Scratch запускается (в т.ч. если установлен в `AppData`).
8. [ ] Запрещённая игра (exe из чёрного списка/папки Загрузки) не запускается; видно сообщение «Это приложение запрещено администратором» либо запуск блокируется AppLocker.
9. [ ] `yandex.ru/games`, `games.yandex.ru`, поддомены и ссылка через редирект блокируются; обычный поиск Яндекса и образовательные сайты открываются.
10. [ ] ⚙ без пароля не открывается; неверный пароль не пускает; после 5 ошибок включается пауза.
11. [ ] Смена пароля работает (старый — нет, новый — да); хэш в `settings.json`, пароля в открытом виде нет.
12. [ ] Добавление нового приложения: появляется на главном экране после «Сохранить и применить».
13. [ ] Смена обоев/цвета/масштаба сохраняется после перезагрузки.
14. [ ] Принудительное завершение `SchoolDesk.exe --ui` (с правами администратора) → интерфейс вернулся за несколько секунд.
15. [ ] ✕ → пароль → обычный рабочий стол; закрыв проводник, вернулся школьный режим.
16. [ ] Ученик не открывает Диспетчер задач, `regedit`, `cmd`, PowerShell.
17. [ ] `Uninstall.ps1` возвращает обычный рабочий стол; политики Chrome/Edge удалены.
