# AgroStat — суфлёр для озвучки

## Публикация через GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `agrostat`.
2. Загрузите в корень репозитория файлы `index.html` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В качестве Branch выберите `main`, папку `/ (root)`, затем нажмите **Save**.
6. Подождите завершения публикации. Адрес сайта будет иметь вид:
   `https://ВАШ-ЛОГИН.github.io/agrostat/`

## Микрофон

Открывайте опубликованный сайт по HTTPS в Chrome и нажмите «Разрешить микрофон».
Если браузер ранее запомнил запрет, откройте настройки разрешений сайта и включите микрофон.
